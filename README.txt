DE TAI PEPTIDE SITE

Всё основное находится в одном app.py:
HTML + CSS + JavaScript встроены в Python-шаблоны Flask.
Дополнительные страницы:
http://127.0.0.1:5000/siami
http://127.0.0.1:5000/founder

ЗАПУСК НА WINDOWS:

1. Установи Python 3 с python.org.
2. Открой папку с app.py.
3. В адресной строке Проводника напиши cmd и нажми Enter.
4. Выполни:
   py -m pip install flask
5. Затем:
   py app.py
6. Открой браузер и введи:
   http://127.0.0.1:5000

Если команда py не работает, попробуй:
python -m pip install flask
python app.py

Остановить сайт:
Ctrl + C в окне CMD.

Это локальный сервер для разработки, а не публичный хостинг.
